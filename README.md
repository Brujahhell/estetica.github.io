# Bella Vita Estética

Landing page moderna e elegante desenvolvida para uma clínica de estética fictícia, criada como projeto de demonstração para portfólio e apresentação comercial de desenvolvimento de sites.

O projeto apresenta uma identidade visual sofisticada e delicada, desenvolvida para transmitir **beleza, cuidado, confiança e profissionalismo**.

## Sobre o projeto

A **Bella Vita Estética** é um conceito de site institucional para uma clínica de estética que deseja apresentar seus tratamentos e serviços de maneira profissional, proporcionando uma experiência visual agradável e facilitando o contato com novos clientes.

O projeto foi desenvolvido com foco em:

* Experiência do usuário
* Design sofisticado
* Responsividade
* Apresentação dos tratamentos
* Construção de credibilidade
* Divulgação da clínica
* Geração de contatos e agendamentos

## Funcionalidades

* Página inicial com apresentação da clínica
* Seção sobre a clínica
* Apresentação dos tratamentos
* Avaliações de clientes
* Galeria de imagens
* Área de agendamento
* Informações de localização
* Seção para redes sociais
* Botão de contato pelo WhatsApp
* Menu responsivo
* Efeitos visuais e interações

## Identidade visual

O design foi pensado para transmitir uma sensação de:

* Elegância
* Beleza
* Sofisticação
* Conforto
* Cuidado
* Profissionalismo

A paleta de cores pode ser facilmente personalizada de acordo com a identidade visual da clínica.
